# 计算、报表与界面

浏览器和 CLI 共用两个纯逻辑模块：

- `src/core.js`：CSV 解析、物理行号、数据校验、整数分运算和筛选。
- `src/reporting.js`：账龄分桶、两份数据对账、结果分页和 CSV 输出。
- `web/app.js`：文件导入、参数失效处理、表格交互及下载。
- `scripts/analyze.cjs`：参数检查和文件读写。

## 三种范围

分析命中使用日期、最低逾期天数及机构筛选。账龄统计使用日期和机构，覆盖全部未结清记录。数据对账覆盖两个文件的全部有效记录，与分析筛选无关；页面搜索只影响表格，不改变统计和导出。这些范围分别显示在页面上。

## 对账约束

按唯一编号关联，比较机构、到期日和整数分余额。记录消失只表示本次文件中缺少记录，不能推断已还款。两个文件任一存在重复编号、日期或金额错误时，对账失败；普通分析仍允许隔离坏行。

金额始终以整数分累计。当前限制为 1 MB、10,000 行、单笔少于十亿元，累计值位于 JavaScript 安全整数范围内。CSV 行引用保留物理行号及原始文本。对账 JSON 保留变更前后完整记录，便于回查。

## 导出与状态

JSON 的 `schema_version` 为 2；新增 `aging`，可选 `comparison`。CSV 导出完整命中列表，金额字段名为 `balance_cents`，以分表示。文本单元格加双引号并转义内部引号；公式起始文本加单引号，防止表格软件当公式执行。

当前数据和参数仅保留在内存，刷新不恢复；需要保留请导出。该版本不连接数据库、DB-GPT 或模型服务。
