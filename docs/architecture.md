# 贷款表格分析：实现说明

```text
CSV → 逐行校验 → 整数分与日期计算 → 条件筛选 → 分组汇总 → 原始行证据
```

浏览器 `web/app.js` 和命令行入口共用 `src/core.js`。核心模块不访问网络、文件或 DOM；读写文件放在命令行层，页面状态和下载放在界面层。

## 可复现输入与输出

`examples/` 保存合成输入及 CLI 的预期输出。测试直接调用核心函数，也通过子进程运行命令行，检查错误退出码、已有文件保护和关键结果。预期文件按命令生成，测试会比对其内容。

## 边界

原项目经历涉及 DB-GPT 部署、模型接口及 Python/pandas 工具。本仓库为 JavaScript 独立实现的公开版本，未接入 DB-GPT 或语言模型；提问解析采用固定句式，不是任意自然语言理解。

浏览器会话是临时状态。源数据或参数改变后必须重新计算/解析；如需保存，请导出 JSON。此原型不包含数据库、账号权限、并发控制或生产监控。
